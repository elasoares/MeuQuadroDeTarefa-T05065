# 📝Meu Quadro de Tarefa

É uma ferramenta visual de organização criada para planejar, acompanhar e concluir atividades do dia a dia de forma prática e intuitiva.
Projeto final do curso de **Programação Web**
---

## ⚙️ Funcionalidade:

- Adicionar uma nova tarefa(digitando e clicando no botão, ou apertando **Enter**).
- Mover a tarefa para frente e para trás entre colunas.
- Excluir tarefa(com confirmação antes). 
- Contador automático de tarefas em cada coluna.

---
## 🛠️ Tecnologias usadas
| Tecnologia | Para que serve|
|------------|---------------|
| HTML       | A estrutura da página |
| CSS        | O visual(cores, layout, mover, excluir) |
| JavaScript | A interatividade(adicionar, mover, excluir) |
